# FIFA World Cup Dashboard (1930-2023) - Power BI



## 📊 Project Overview
A comprehensive Power BI dashboard analyzing FIFA World Cup data from 1930 to 2023. This project includes data extraction from Kaggle, data cleaning with pandas, data modeling in Power BI, and interactive visualizations.

## 🎯 Features
- **Historical Analysis**: World Cup data from 1930 to 2023
- **Team Performance**: Country-wise statistics and rankings
- **Player Insights**: Top scorers and player performances
- **Match Analysis**: Detailed match statistics and outcomes
- **Interactive Filters**: Year, country, and tournament phase filters

## 🛠️ Technologies Used
- **Python**: Data extraction and cleaning (pandas, numpy)
- **Power BI**: Data modeling and visualization
- **Kaggle**: Data source
- **Jupyter Notebooks**: Data analysis and experimentation

📈 Data Pipeline
Data Extraction: Raw data from Kaggle

Data Cleaning: Handle missing values, standardize formats

Feature Engineering: Create new metrics and dimensions

Data Modeling: Power BI data model relationships

Visualization: Interactive dashboard creation
